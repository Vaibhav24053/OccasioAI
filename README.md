# OccasioAI — Your AI Event Planning Assistant

**Plan meaningful events without the planning chaos.**

OccasioAI is an AI-powered event planning assistant that helps people organize weddings, birthdays, parties, and community events in one place. From creating an event blueprint to managing budgets, guests, vendors, and schedules, OccasioAI brings the entire planning process together.

**[Try the Live App](https://plan-occasio-magic.base44.app/) · [GitHub Repository](https://github.com/Vaibhav24053/OccasioAI)**

## Why OccasioAI?

Event planning often means juggling spreadsheets, guest lists, budgets, vendor conversations, and last-minute changes. OccasioAI brings these moving parts into one workspace and uses AI to help turn an event idea into an actionable plan.

## Features

- **AI Event Blueprints** — Turn an event idea into a structured starting plan.
- **Planning Dashboard** — Keep event details, upcoming tasks, and progress in one place.
- **Budget Management** — Organize expenses by category and rebalance your budget.
- **Guest Management** — Maintain guest lists and prepare invitation messages.
- **Vendor Coordination** — Manage vendors and prepare quote requests and outreach.
- **Timelines and Run Sheets** — Organize tasks, event schedules, and contingency plans.
- **AI Planning Tools** — Generate ideas, timelines, and other planning materials through dedicated backend functions.
